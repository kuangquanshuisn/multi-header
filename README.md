# Multi Header · 请求头管理

基于 Manifest V3 的 Chrome 扩展，按环境为 HTTP / HTTPS 请求统一添加或覆盖请求头，适用于开发调试和测试环境切换。

## 功能

- 管理多组环境，支持添加、重命名和删除，一次仅启用一个环境。
- 每个环境可配置多条 Key / Value，请求头支持独立开关。
- 全局开关可暂停或恢复请求头修改。
- 有效修改自动保存，保存成功后对新请求生效。
- 配置保存在本机，支持通过「展开」进入完整管理页面。
- 扩展图标角标显示生效请求头数量，暂停时显示 `OFF`。

## 安装

需要 Chrome 101 或更高版本。

1. 下载或克隆本项目到本地。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
5. 在浏览器扩展菜单中固定 Multi Header，方便随时切换环境。

扩展使用原生 JavaScript，无需安装依赖或构建即可加载。更新代码后，在扩展管理页点击「重新加载」。

## 使用

1. 点击扩展图标，使用默认的「开发环境」，或点击「添加环境」创建环境。
2. 点击「添加请求头」，填写 Key 和 Value，例如：

   | Key | Value |
   | --- | --- |
   | `X-Environment` | `development` |
   | `X-Debug` | `true` |

3. 确认全局开关和对应请求头开关已开启，底部显示「已自动保存」。
4. 刷新目标网页或重新发起请求，在开发者工具的 Network 面板中查看请求头。

点击左侧环境即可切换生效配置。关闭某条请求头的开关可停用该条覆盖规则；关闭全局开关可暂停所有覆盖规则。

### 生效范围与配置约束

- 规则作用于浏览器允许扩展修改的所有 HTTP / HTTPS 请求，包含页面导航和页面资源请求，目前不支持按域名或 URL 配置作用范围。配置身份凭据等敏感请求头前，请确认这一范围符合使用需求。
- 同名请求头使用 `set` 操作添加或覆盖，不会将多个环境的配置合并。
- 最多支持 50 个环境，每个环境最多 100 条请求头，至少保留一个环境。
- 环境名称需为 1–40 个字符，且不能重复。
- 请求头 Key 不区分大小写，同一环境内不能重复；Value 允许为空，不能包含换行或非法控制字符。
- Key 和 Value 均为空的行不参与请求头修改。填写 Value 后必须填写有效 Key。

## 保存与排查

- **配置未生效**：检查当前环境、全局开关、请求头开关和底部保存状态，再重新发起请求；已发出的请求不会被追溯修改。
- **配置校验或保存失败**：界面会显示原因，浏览器继续使用上次成功保存的配置。修正后重试，或点击「重新加载」恢复已保存配置。
- **多个窗口编辑发生冲突**：按提示点击界面底部的「重新加载」，读取最新配置后再编辑；该操作会丢弃当前未保存的修改。
- **无法连接扩展**：到 `chrome://extensions/` 重新加载扩展，再打开管理界面。

## 本地开发

开发检查需要支持 `node --test` 的 Node.js，建议使用 Node.js 22 或更高版本。

```sh
npm test
npm run check
```

`npm test` 运行核心配置、规则生成及后台消息处理等自动化测试；`npm run check` 检查 JavaScript 语法。浏览器界面及实际请求头效果需加载扩展后验证。

### 项目结构

```text
.
├── manifest.json          # 扩展声明、权限和入口
├── background.js          # 后台消息处理、规则应用和图标状态
├── core.js                # 配置校验、规则生成及保存逻辑
├── popup.html             # 弹窗和完整管理页
├── popup.js               # 环境与请求头编辑交互
├── styles.css             # 界面样式
├── icons/                 # 扩展图标
└── test/                  # 自动化测试
```

## 权限与存储

| 权限 | 用途 |
| --- | --- |
| `storage` | 使用 `chrome.storage.local` 保存环境和请求头配置，不进行浏览器账号同步。 |
| `declarativeNetRequestWithHostAccess` | 通过浏览器声明式规则修改请求头。 |
| `http://*/*`、`https://*/*` | 允许规则应用于 HTTP / HTTPS 站点。 |

扩展不依赖外部服务，不主动上传配置。启用的请求头会随匹配的请求发送至目标站点。
